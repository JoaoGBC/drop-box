## Introdução:

O que essa aplicação pretende fazer é agir como um 'drop-box': isso é, permitir o upload de grandes quantidades de arquivos para um object-storage e a recuperação futura desses arquivos. Toda a infra desse projeto esta rodando em um servidor local: isso inclui o object-storage em si, bem como a infra de suporte (proxys, webserver, etc). É meu primeiro projeto ~publico~ em que faço a gerencia de toda essa infra de forma autonoma.
